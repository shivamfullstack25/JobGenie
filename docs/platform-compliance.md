# Platform Compliance

**Researched:** 2026-10-06. **Review before each adapter is built and at least quarterly**; terms change. This is an engineering reading of published terms and documentation, not legal advice.

## Rules that apply to every platform

JobGenie never bypasses CAPTCHA, MFA, anti-bot systems, rate limits, authentication or access controls. It never uses proxy rotation or fingerprint spoofing to avoid detection, never extracts cookies or credentials, never operates accounts it does not own. Detecting which ATS hosts a job grants no permission to automate it. Where a platform's position is unknown, the mode is `DRAFT_ONLY`.

## Automation modes

| Mode | Meaning |
|---|---|
| `FULLY_AUTOMATED` | JobGenie performs the action without a human step. Allowed only where the platform's published terms or API explicitly permit it. |
| `HUMAN_APPROVAL` | JobGenie prepares; a human approves in the Approval Center; JobGenie then performs it through a permitted channel. |
| `BROWSER_ASSISTED` | The user is at the controls in their own browser session. JobGenie supplies prepared content to copy or review. JobGenie does not drive the page. |
| `DRAFT_ONLY` | JobGenie produces text and documents. The user does everything else. |
| `BLOCKED` | JobGenie does not perform the action in any form. |

## Sources with a permitted read path

### Adzuna
- **Search:** Official REST API, `GET /v1/api/jobs/{country}/search/{page}`. Country codes cover India, US, UK, Canada, Germany, Netherlands, Singapore, Australia and others.
- **Rate limits (default key):** 25 per minute, 250 per day, 1,000 per week, 2,500 per month.
- **Restrictions:** Results must display the "Adzuna" label (minimum 116×23 px) linked to Adzuna. Commercial organizations get a 14-day trial; continued use may require written consent or a licence. One account only.
- **Apply:** Follow `redirect_url`. No application API.
- **Action required in JobGenie:** add the attribution to every Adzuna-sourced card (missing today); budget the cache around 250 calls per day; obtain a licence before any commercial launch.

### Greenhouse
- **Search:** `GET https://boards-api.greenhouse.io/v1/boards/{board_token}/jobs`. Documentation: "Job Board data is publicly available, so authentication is not required for any GET endpoints."
- **Apply:** `POST …/jobs/{id}` requires Basic Auth with the employer's Job Board API key. Not available to JobGenie.
- **Limits:** none stated; self-impose at most one request per second per board and cache for hours.
- **Note:** there is no directory of board tokens. JobGenie needs a curated list of employers.

### Lever
- **Search:** `GET https://api.lever.co/v0/postings/{site}` (EU: `api.eu.lever.co`). "All job postings in the published state are publicly viewable."
- **Apply:** POST needs an API key generated by the employer's Super Admin. Not available. The documentation directs sites without one to Lever's hosted form.
- **Limits:** 2 application POSTs per second (irrelevant to us); be conservative on GET.

### Ashby
- **Search:** `GET https://api.ashbyhq.com/posting-api/job-board/{name}`, optional `includeCompensation=true`. The documentation presents it as a public posting API; it does not state an authentication requirement or a rate limit. Confirm with a test call before relying on it.
- **Apply:** response includes `applyUrl` to Ashby's hosted page.

### SmartRecruiters
- **Search:** `GET https://api.smartrecruiters.com/v1/companies/{id}/postings`, reported public for published postings; not every customer has the feed enabled. Read the primary developer terms before building.
- **Apply:** hosted page.

## Platforms where automation is not permitted

### LinkedIn (restricted)
- **User Agreement, effective 2025-11-03, §8.2.2:** users must not "develop, support or use software, devices, scripts, robots or any other means or processes (such as crawlers, browser plugins and add-ons or any other technology) to scrape or copy the Services, including profiles and other data."
- **§8.2.13:** users must not "use bots or other unauthorized automated methods to access the Services, add or download contacts, send or redirect messages, create, comment on, like, share, or re-share posts."
- **API:** partner programmes only (Talent, Marketing, Sign In with LinkedIn via OpenID Connect). No job-search or apply API for candidate tools. Sign-in returns basic identity only.
- **Authentication:** OAuth 2.0 for approved products. JobGenie never asks for or stores a LinkedIn password.
- **JobGenie may:** generate headline, About, experience wording, skills and recruiter-keyword strategy as a `LinkedInProfileDraft` (`currentValue`, `proposedValue`, `reason`, `keywords`, `evidence`, `approvalStatus`) for the user to paste in themselves; open a LinkedIn job URL in the user's browser.
- **JobGenie must not:** scrape search results or profiles, automate Easy Apply, send messages or connection requests, or run any extension that acts on linkedin.com.
- **Existing code in breach:** `LinkedInJobScraper` in `job_aggregator.py`. Scheduled for removal. The gateway's OAuth handler uses retired scopes and overwrites profile data; it is to be disabled until rebuilt on OpenID Connect as sign-in only.

### Indeed
- **Terms (as reported):** prohibit using "any automated system (bots, scrapers, spiders, AI or Agentic AI) to access, data-mine, or submit content to the Site, in bulk or otherwise, without Indeed's express written permission." The wording names agentic AI specifically.
- **API:** the Publisher job-search API is closed to new developers and retired. Indeed Apply and sponsored-jobs APIs are partner-only.
- **Existing code in breach:** `IndeedJobScraper`. Scheduled for removal.

### Naukri
- **Terms (as reported):** users undertake not to duplicate, download or distribute site material without authorization from Info Edge; commercial derivative use needs written consent. robots.txt disallows several AI crawlers by name. The site runs commercial bot protection.
- **API:** no self-serve public API. "Naukri integration" in recruiter products is a negotiated commercial arrangement on the employer side.
- **JobGenie may:** `NaukriProfileAgent` produces headline, summary, key skills, experience text, preferred roles and locations, expected salary and notice period as drafts for manual entry. Note for the product: Naukri profile freshness affects recruiter search ranking, and users commonly ask for automated daily "profile refresh". That is automated access and stays `BLOCKED`; a reminder notification is the compliant substitute.
- **Existing code in breach:** `NaukriJobScraper`. Scheduled for removal.

### Instahyre
- **Terms of Use (as reported):** prohibit using "manual or automated software, devices, or other processes to crawl or spider any part of the Platform" and accessing, searching, copying, monitoring, harvesting or scraping it.
- **API:** integrations are employer-side ATS connectors. No candidate API found. The JSON endpoint the site's own search page uses is not an offered public API; using it is covered by the same prohibition.
- **`InstahyreAdapter`:** profile-optimization drafts, application preparation, and manual tracking (the user records what they did). `searchJobs()` returns `BLOCKED_BY_PLATFORM`.

### Cutshort
- **Finding:** Cutshort publishes an official public API and MCP server. It is a **recruiter-side** product: search the talent database, post jobs, unlock profiles, run outreach, authenticated with a workspace API key. No candidate-side job-search or apply capability was found. The many "Cutshort MCP" listings on Apify are third-party scrapers, not official.
- **`CutshortAdapter`:** `DRAFT_ONLY` and `BROWSER_ASSISTED` until Cutshort confirms in writing a candidate-side integration. One action item: ask Cutshort directly whether candidate access exists or is planned.

### Wellfound, Glassdoor, Monster, Hirist
No official candidate API identified. Wellfound is reported to block automated access aggressively. Glassdoor's public API has been closed for years. Primary terms were not read in this pass, so all are default-deny. `GlassdoorJobScraper` and `MonsterJobScraper` are scheduled for removal.

### Google Jobs
Google's job search experience has no public query API. Cloud Talent Solution is for searching a company's own job inventory. Scraping Google results breaches Google's terms. `BLOCKED`.

### Workday and other enterprise ATS
Workday's REST and SOAP APIs need tenant credentials and do not expose public listings. Career sites sit on per-employer domains with per-employer terms and frequently require a candidate account. Detection is fine; reading or applying programmatically is `BLOCKED` unless a specific employer's terms are reviewed and recorded as a `PlatformPolicy` row.

## How this is enforced in code

1. A `platform_policies` table holds one row per platform and action (`SEARCH`, `PROFILE_UPDATE`, `APPLY`, `MESSAGE`) with `mode`, `sourceUrl`, `reviewedAt`, `reviewedBy`, `notes`. Rows older than 120 days degrade to `DRAFT_ONLY` until re-reviewed.
2. Every `JobSourceAdapter` returns its policy from `getCompliancePolicy()`; the orchestrator refuses an action whose mode is below what the action needs. The adapter cannot override the table.
3. `GLOBAL_AUTOMATION_ENABLED=false` by default; a per-platform `enabled` flag; `DRY_RUN=true` by default. All three must allow an action for it to run.
4. Compliance tests assert, for every adapter, that a `BLOCKED` action makes no network call (verified with a mocked HTTP layer) and that no adapter contains credential fields for a third-party site.
5. On encountering a CAPTCHA, MFA prompt, login wall or unknown challenge, any browser workflow stops, records `BLOCKED_BY_PLATFORM`, and hands control to the user.
